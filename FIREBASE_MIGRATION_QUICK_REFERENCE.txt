# Test profile update
curl -X PUT -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Test"}' \
  http://localhost:3001/api/user/YOUR_ID

## ⚠️ If Tests Fail

Check these things:

1. **Backend running?**
   ```bash
   ps aux | grep "node.*server"
   # Should show backend process running
   ```

2. **MongoDB connected?**
   - Check backend logs for connection errors
   - Verify MongoDB is running

3. **API endpoints exist?**
   - Test with curl (see "Quick Test" above)
   - Check backend routes

4. **Token valid?**
   - Verify `localStorage.getItem("auth_token")` has value
   - Try logging out and back in

5. **CORS enabled?**
   - Frontend on http://localhost:5173
   - Backend should allow this
